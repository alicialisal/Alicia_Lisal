MOMEASE

MomEase – Mobile Health Application

Overview

MomEase is a mobile application designed to support maternal mental health through journaling, self-assessment, and educational content. The system focuses on helping users track emotional states and access relevant resources in a structured and accessible way.

Problem

Many mothers experiencing early symptoms of Baby Blues lack accessible tools to:

  • track their emotional condition consistently
  • understand their mental state
  • access reliable and structured support

Most available solutions are either too complex or not personalized enough.

Solution

I contributed to building a mobile-based solution that enables users to:

  • record daily moods through journaling
  • perform self-assessment for mental health monitoring
  • access curated educational content

The system is designed to be simple, intuitive, and accessible for non-technical users.

My Role

Back-End Mobile Developer & Database Designer

  • Developed RESTful APIs using Laravel for CRUD operations (journaling, assessment, content)
  • Designed relational database schema (MySQL) to ensure structured and scalable data storage
  • Integrated backend services with Flutter frontend for seamless data flow
  • Handled data processing for user inputs and feature interactions

Tech Stack

Frontend Flutter (Dart)
Backend Laravel (PHP)
Database MySQL
Architecture REST API

Challenges

  • Integrating backend (Laravel) with mobile frontend (Flutter) efficiently
  • Designing a database that supports multiple features (journaling, assessment, content)
  • Handling data flow between different modules while maintaining performance

Impact

  • Delivered a functional end-to-end mobile application with backend integration
  • Enabled structured tracking of user mood and self-assessment data
  • Improved understanding of full-stack development workflow (API ↔ mobile ↔ database)
