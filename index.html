COVID 19 Vaccine Demand Prediction

Overview

A machine learning-based vaccine demand prediction system using Apache Spark and Random Forest to forecast weekly COVID-19 vaccine needs across EU/EEA countries using large-scale ECDC vaccination data. The project processed over 800,000 vaccination records from 30 EU/EEA countries to build a scalable prediction pipeline for short-term vaccine demand forecasting. The system used distributed big data processing and time-series feature engineering to support vaccine logistics planning.

Problem

  • Vaccine demand fluctuated significantly during the COVID-19 pandemic.
  • Supply-demand imbalance caused delays and unequal vaccine distribution.
  • Large-scale vaccination datasets were difficult to process efficiently using traditional methods.

Solution

I contributed to build a vaccine demand prediction system, where i:

  • Built a distributed data processing pipeline using Apache Spark.
  • Engineered lag-based and seasonal time-series features from vaccination history.
  • Trained country-specific Random Forest models for weekly vaccine demand prediction.
  • Evaluated model performance using R2, MAE, and RMSE metrics across different countries.

My Role

ML Developer

  • Performed data preprocessing and feature engineering using PySpark.
  • Developed lag and seasonal feature generation pipelines.
  • Assisted in Random Forest model training and evaluation.
  • Contributed to research writing, analysis, and result interpretation.

Tech Stack

Big Data Apache Spark
Machine Learning Random Forest
Framework PySpark
Dataset ECDC Vaccination Data

Challenges

  • Handling over 800,000 records with heterogeneous vaccination patterns across countries
  • Managing inconsistent and sparse vaccination data from several countries

Impact

Thermal Rat Detection

Thermal Rat Detection for Farmers

Overview

A real-time nocturnal rat detection system combining thermal camera imagery and YOLOv11 object detection, deployed to solve an actual pest problem identified during fieldwork in Desa Sengka. Detection triggers an automatic ultrasonic deterrent.

Problem

Farmers often face:

  • Night-time rat attacks that are difficult to detect
  • Ineffective traditional monitoring methods
  • Limited access to affordable automated detection systems

Solution

We collected thermal rat datasets from Roboflow and Kaggle and developed a computer vision project that:

  • Collected and unified thermal rat datasets into YOLO format.
  • Applied thermal-specific data augmentation to improve detection robustness
  • Integrated real-time rat detection with automatic ultrasonic activation.

My Role

ML Developer & Lead Author

  • Collected thermal datasets and converted segmentation annotations into YOLO bounding-box format
  • Developed a thermal-image augmentation pipeline to improve model robustness and detection accuracy
  • Trained and evaluated the YOLOv11-based thermal rat detection system for real-time inference
  • Integrated automated ultrasonic activation triggered by detection events
  • Contributed to academic research writing and project documentation

Tech Stack

Training Environment Google Colab GPU
Dataset Sources Kaggle & Roboflow
Detection Model YOLOv11

Challenges

  • Thermal images lacked RGB texture and color information, requiring specialized augmentation techniques.
  • The Kaggle dataset used segmentation masks, requiring custom conversion into YOLO bounding-box annotations.
  • No thermal camera hardware was available, so development relied entirely on open-source datasets and YouTube thermal videos.
  • Model evaluation used unseen real-world thermal videos to better test generalization performance.

Impact

The system achieved mAP@50 above 0.99, precision 0.989, and recall 0.981, performance strong enough to operate reliably as an early-warning system. During inference testing, the model consistently detected rats in external thermal video and successfully triggered the ultrasonic emitter module.

What I'd Improve Next

  • Deploy on a Raspberry Pi or Jetson Nano with an actual thermal camera for in-field validation
  • Extend detection to multiple pest species (snakes, insects) by expanding the dataset
  • Build a mobile alert system so farmers receive real-time notifications on their phones
